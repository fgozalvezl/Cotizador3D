# App original (Python)

`cotizador.py` es la version 1 de Cotizador3D, en Python + customtkinter. Se
conserva solo como referencia: su comportamiento esta documentado en
`docs/SPEC-legacy.md` (las citas `cotizador.py:linea` apuntan a este archivo).

La version 2 (.NET 8 / WPF) vive en `src/` y lee el mismo archivo de
configuracion, asi que no hace falta migrar nada.
